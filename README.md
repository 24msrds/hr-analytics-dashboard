# 📊 HR Analytics Dashboard

An end-to-end Power BI dashboard analyzing employee attrition drivers across 1,470 employee records, built to surface actionable workforce insights for HR decision-making.

## 🎯 Overview
This project consolidates raw HR data (based on the IBM HR Analytics dataset) into a 3-page interactive Power BI dashboard, using DAX measures and AI-powered visuals to identify what drives employee attrition.

## 🛠 Tools & Tech
- **Power BI Desktop** — dashboard design & data modeling
- **DAX** — 6+ custom measures
- **Power Query** — data cleaning & transformation
- **Excel** — source data preparation

## 📈 Key Features
- 3-page interactive dashboard (Overview, Attrition Analysis, Department Deep-Dive)
- 6+ custom DAX measures (attrition rate, average tenure, overtime impact, etc.)
- AI visuals: **Key Influencers** and **Decomposition Tree** to auto-surface attrition drivers
- Department-level and role-level attrition breakdown

## 🔍 Key Insights
- Identified **overtime** and **department** as top attrition drivers
- Surfaced attrition rate patterns across job roles and tenure bands
- Enabled drill-down analysis from company-wide to individual department level
